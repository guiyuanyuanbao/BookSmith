# BookSmith 前端体验重构设计

## 用户痛点梳理

| # | 痛点 | 方案 |
|---|---|---|
| 1 | 导出文件全堆一页，找不到哪本书的 | 导出按书分组展示；书架卡片直接显示该书导出文件 |
| 2 | 搜索页大片空白，搜索框在左上角 | 居中 hero 布局（大标题+大搜索框垂直居中），搜索后切换为结果列表 |
| 3 | 缺设置页 | 新增：主题色（5 种配色）、默认下载并发、默认导出格式、书架默认视图 |
| 4 | 书架只有单列列表 | 双视图：卡片网格（多行多列）/ 列表（单列），可切换记忆 |
| 5 | 封面缺失 | 多源封面 fallback：搜索结果已按书聚合 origins（含各源 coverUrl），前端自动选第一个有封面的源 |
| 6 | 缺批量管理 | 书源：勾选批量启用/禁用/删除；书架：勾选批量移除/导出 |
| 7 | 缺统计 | 侧栏底部 + 独立"概览"页：源健康分布、书架/任务/导出计数、最近活动 |
| 8 | 元素大小/对齐/圆角不统一 | 全局 design tokens 已有，继续打磨页面级细节 |

## 页面职责（重构后）

```
概览(/overview)    统计仪表盘 + 快捷入口
搜索(/search)      hero 居中 → 流式结果 → 比源 → 下载
书架(/books)       资产中心：双视图、进度、续传、导出文件入口、批量操作
任务(/tasks)       监控台：进度/暂停/取消/重跑
导出(/files)       按书分组的成品列表
书源(/sources)     供给管理：批量操作工具栏
净化(/rules)       规则管理
设置(/settings)    主题色/并发/默认格式/视图偏好
```

## 后端新增

- `GET /api/overview` — 统计聚合（源健康计数、书架数、任务状态计数、导出数/大小）
- `GET /api/exports?bookId=` — 按书过滤导出
- `POST /api/sources/batch` — 批量操作 {action: enable/disable/delete, urls[]}
- `POST /api/books/batch` — 书架批量 {action: remove, ids[]}
- 设置持久化：复用 kv 表 `GET/PUT /api/settings`
